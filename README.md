# SafeRoute AI

SafeRoute AI is an AI powered urban route planning application designed to help users identify safer routes by analyzing route risk and contextual factors.

The system combines machine learning based risk analysis with an AI powered backend and an interactive Streamlit frontend to provide safety focused route recommendations.

## System Architecture

The Streamlit frontend collects user inputs and displays route recommendations and safety information.

The FastAPI backend processes requests and connects the machine learning and AI components.

The machine learning layer performs risk analysis and supports safer route recommendations.

The AI layer provides intelligent assistance based on the processed route and safety information.

## Project Structure

backend contains the FastAPI backend and API services

frontend contains the Streamlit user interface

ml contains machine learning models and prediction logic

Dockerfile contains the backend deployment configuration

requirements files contain the project dependencies

## Deployment

The FastAPI backend is deployed on Render using Docker.

The Streamlit frontend is deployed using Streamlit Community Cloud.

The frontend communicates with the deployed backend through the backend API.

## Purpose

SafeRoute AI aims to improve urban navigation by considering safety related factors along with route information rather than focusing only on distance and travel time.
